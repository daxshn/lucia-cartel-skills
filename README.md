# Lucia Cartel Skills

Website for the [Lucia Cartel](https://www.youtube.com/@LUCIACARTEL) YouTube channel. It shows the Claude Code skills behind the channel's shorts, with clips made by each one playing beside a download button.

- Static site: `index.html`, `styles.css`, `app.js`
- `media/` holds 9-second silent loops and posters
- `downloads/` holds the skill zips

Skills: doodle-shorts-remotion, ClaudeAnimationBase1, in-this-city-gta-short, faceless-shorts, cartoon-audio-short.

Hosted on Vercel; every push to `main` redeploys.
