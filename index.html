Every skill on one shelf

Each one is a folder you drop into Claude Code. Ask for a video and it writes the script, builds the scenes and renders the MP4. The clips playing on each card were made with it. Film styles come from Lemo-Opuscar by Lemomo and are free for non-commercial use, with credit.

Set one up in two minutes

  1. Download and unzip

    Pick a skill above and unzip it. You get one folder with a SKILL.md inside.

  2. Move it into your skills folder

    Put the folder in ~/.claude/skills/. On Windows that is C:\Users\you\.claude\skills\.

  3. Ask Claude for a video

    Open Claude Code and say what you want, like “use the faceless-shorts skill to make a short about why we get goosebumps.”

For a film style, unzip it into your project and tell Claude: “read STYLE.md and DEMO.md, then make my short in this style.”

ClaudeAnimationBase1 is a project, not a single skill: unzip it anywhere, run npm install, then open the folder in Claude Code.

About the channel

Lucia Cartel is a faceless shorts channel. Every video answers one question in under two minutes: what if you swallowed your phone, why can't you remember being a baby, how a glider landed a jet with empty tanks.

Nothing is filmed and nothing is stock. Characters, cities and captions are all drawn by code that Claude writes, using the skills on this page. 3.04K people subscribe so far, across 27 videos.
